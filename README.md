# 晨间十条 · Morning Ten 1.4.0

原生 macOS 新闻阅读器。用自己的主题与关键词整理新闻，只显示能够读取并核对标题的原始发布。

## 1.4.0

- 可折叠侧边栏、系统字体、简洁卡片与应用内阅读视图，自动跟随系统浅色或深色外观。
- 设置中切换简体中文、English 或跟随系统；界面、预设主题、菜单、通知、标题和摘要使用所选语言。
- 公司名、产品名和专业缩写保留发布者使用的原文，例如 NVIDIA、OpenAI、SpaceX、GPU。可添加自定义保留术语。
- 翻译按语言、原文内容和保留术语分别缓存；同一链接内容更新后不会继续显示旧译文。翻译失败可重试，原文始终可读。
- 搜索同时匹配原始文本与已有译文。主题页面的翻译会覆盖全部可见文章。
- 来源标题按完整词核对，避免长单词中的相同字母造成误判；刷新和单篇重试协调执行，重定向后的同一原文去重。

## 使用

需要 macOS 15 或更新版本，支持 Apple Silicon 与 Intel。

在 **设置 → 语言与翻译** 选择语言。系统翻译在本机处理，不需要 API 密钥；首次使用可能需要你允许下载 Apple 的语言包。关闭新闻翻译可直接阅读发布者原文。已识别的名称、缩写及自定义术语受保护；如果翻译丢失受保护的名称，该结果不会被展示，可以重试。自动识别无法穷尽所有专业名称，重要术语可在设置中补充。

在 **设置 → 关注主题** 中新增、编辑、开启、关闭或删除主题。关键词用逗号或换行分隔，任一词匹配即可；英文短语按完整短语匹配。中文主题建议同时加入英文同义词。关键词匹配已配置的一手来源，并检索 Federal Register 公告和 arXiv 论文；不保证覆盖所有主题。

点击标题在应用中阅读摘要、对照原文；点击来源或“原文”会重新检查对应文章后打开完整原文。使用单篇的重试按钮或顶部更多菜单中的“重新验证全部来源”重新连接。

## 来源规则

遵循 Research 的一手资料优先要求：政府原始文件、公司正式公告和原创论文。来源的名称和链接对应具体文章，不以首页或搜索结果替代原文。无法读取、错误页、挑战页、无关标题或跳出发布者域名的内容不会展示。没有合规来源时，新闻可以少于十条或保持空白。

页面核验不代表独立证实发布者的研究结论；公司自述保留归属，arXiv 预印本注明未经同行评审。当前来源池不使用 Wikipedia、论坛或媒体转述填补空缺。

## 构建与验证

安装 Apple Command Line Tools 或 Xcode 后运行：

~~~sh
./build.sh
~~~

构建会运行核心与语言流程检查、生成 arm64/x86_64 通用应用并验证签名。输出为 dist 下的应用、压缩包与 SHA-256 校验文件。可用 MORNINGTEN_SWIFTC、MORNINGTEN_SDK、MORNINGTEN_LIPO 指定工具路径。

应用在 Contents/Resources/Source 中附带本版本源码、资源、测试和构建脚本。Tests/InterfaceChecks.swift 的可选渲染模式使用隔离设置和示例数据，不修改个人新闻与偏好。

## 隐私

个人主题、偏好、新闻、翻译、浏览器会话、API 密钥与凭据不属于仓库提交。新闻与主题保存在本机 Application Support，偏好使用本机应用设置。源码和发布包不包含这些个人数据。
